# Презентация команды

## Путеводитель по МГРИ

Путеводитель для новых студентов колледжа и университета МГРИ: знакомит с местом проведения занятий, его историей и тем, как проходит учёба.

## О проекте

Поступление в колледж или университет — это новая среда: незнакомое здание, множество аудиторий, непонятно, куда идти. Путеводитель помогает новым студентам быстрее познакомиться с учебным заведением и освоиться.

**Цель** — ознакомить новых студентов с местом проведения занятий и его историей.

**Задачи:**

1. Показать историю колледжа и университета.
2. Показать, как учатся студенты.
3. Создать макет путеводителя и наполнить его информацией.
4. Оценить эффективность путеводителя.

## Состав проекта

| Часть | Что входит |
|---|---|
| Авторская разработка | Макет путеводителя Макет мини-карты первого этажа |
| Реализация разработки | Наполнение контентом: история МГРИ, информация об учёбе студентов, перечень аудиторий, список объектов, фотографии |

## Cтруктура сайта-путеводителя:

1. Главная страница -  приветствие, ознакомление с историей МГРИ
2. Карта первого этажа - список аудиторий и план первого этажа
3. Фотогалерея - фото секций и аудиторий
4. Достижения МГРИ - перечень достижений университета и коледжа.


## Приложения

- **Таблицы** - перечень аудиторий; список объектов МГРИ.
- **Фотографии** - здание, аудитории и достопримечательности университета.
- **Видео** - понятный видеоматериал для первокурсника как добратся до не очивидных мест.
